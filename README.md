# Каталог техники ОКСМА

Многостраничный сайт-каталог на PHP 8.1+, HTML, CSS и JavaScript. База данных и административная панель не используются: разделы, товары, характеристики и изображения хранятся в `data/catalog.php`.

## Готовые страницы

- главная `/`;
- типовая категория `/catalog/zagruzchiki-suhih-kormov/`;
- типовой товар `/product/zsk-10/`;
- политика конфиденциальности `/privacy/`;
- SEO-файлы `/robots.txt` и `/sitemap.xml`;
- собственная страница 404.

## Локальный запуск

```powershell
php -S 127.0.0.1:8765 router.php
```

Откройте `http://127.0.0.1:8765/`.

## Проверки

```powershell
php tests/php/run.php
node --test tests/js/*.test.mjs
python scripts/validate_tokens.py
python scripts/validate_contrast.py
```

## Где менять контент

- реквизиты, телефоны и email: `config/app.php`;
- товары, категории и характеристики: `data/catalog.php`;
- SMTP без публикации пароля: `config/mail.php`;
- изображения: `assets/images/`.

## Демоверсия на Vercel

Оригинальный сайт в корне репозитория является основной PHP-версией для обычного хостинга. Папка `vercel-demo/` — автоматически сгенерированная статическая копия для показа клиенту. Не редактируйте файлы внутри `vercel-demo/` вручную.

После любых изменений оригинального сайта обновите демоверсию одной командой:

```powershell
php scripts/export-vercel-demo.php
```

Экспортёр заново создаст главную, все актуальные категории и товары, документы, политику, sitemap, robots, страницу 404 и публичные ресурсы. Отправка форм в демоверсии отключена с понятным уведомлением; остальные клиентские функции продолжают работать.

Для первой публикации:

1. В Vercel выберите **Add New → Project** и импортируйте `rez1dennt/oksma`.
2. В поле **Root Directory** укажите `vercel-demo`.
3. **Framework Preset** оставьте `Other`.
4. **Build Command** и **Output Directory** оставьте пустыми.
5. Нажмите **Deploy**. Production Branch должна быть `main`.

После подключения каждый следующий push в `main` автоматически обновит публичную демоверсию.

Подробная инструкция по публикации находится в [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md).
